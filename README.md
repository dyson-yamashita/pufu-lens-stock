# Pufu Lens

気になった記事や自分のメモを集め、問いを深め、行動につなげるためのアプリです。

Web・Xの投稿のURLやテキストをプロジェクトごとにストックすると、AIが要約と問いを生成します。集めた情報から関心や知識を「メモリ」に整理し、問いを解決するための「プ譜（プロジェクト譜）」を作成・編集できます。

## できること

- **集める** — URLやテキストを保存。iPhoneのショートカットやMCPからも追加できます。
- **読み返す** — 要約・本文・メモを確認し、検索やお気に入りで探せます。
- **考える** — AIが生成した問いや、自分で追加した問いを蓄積できます。ストックなしの問いも保存できます。
- **つなげる** — プロジェクトごと、ユーザー全体の関心と知識をメモリとして更新します。
- **行動にする** — 問いに対する課題を入力してプ譜を生成。編集と振り返りを局面として保存できます。

Googleアカウントでログインし、複数のプロジェクトを管理します。記事・問い・メモリ・プ譜はユーザーごとに保存されます。

## まずはローカルで試す

**Node.js 22.18以降の22系、または24.11以降（推奨24系） / pnpm 10.34.7** を使用します。Corepackを使う場合は、初回に `corepack enable` を実行してください。

```sh
pnpm install --frozen-lockfile
pnpm run setup
pnpm run dev
```

[http://localhost:5173/](http://localhost:5173/) を開き、「ローカルデモを開く」を選びます。CloudflareやGoogleの認証情報なしで試せます。

デモにはサンプル記事が含まれます。AI未接続時は本文の抜粋や定型の案を使い、保存からプ譜の編集までの流れを確認できます。本物のAI生成を試す場合は、[Workers AIの設定](docs/SPEC.md#ローカルでworkers-aiを使う)を参照してください。AIへ送った資料はCloudflareで処理され、利用量に応じて料金が発生します。

## 基本の使い方

1. プロジェクトを作り、「記事をストック」からURLまたはテキストを保存します。
2. 要約を読み、生成された問いを確認します。「問いを追加」から自分の問いも残せます。
3. 問いの詳細で「問いの解決を考える」を選び、実現したいことを課題として入力します。
4. 「プ譜を作成」で案を生成し、編集・保存します。局面を追加すると、編集と振り返りを続けられます。

プロフィールの自己紹介やプロジェクト概要を書くと、メモリやプ譜の生成に背景情報を反映できます。

退会は「プロフィール」から行えます。登録データ・保存本文を削除し、全端末のセッションと連携を無効にします。削除したデータは復元できません。[退会について](docs/SPEC.md#退会)を参照してください。

詳しい操作は、アプリ内の「ユーザーマニュアル」を参照してください。

## 外部サービスとの連携

- **iPhone** — 共有シートから記事を保存できます。[ショートカットの設定](docs/SPEC.md#iosショートカット)を参照してください。
- **ChatGPTなど** — MCP連携でストックや問いを追加・検索し、保存済みのプ譜をJSONや画像で確認できます。[MCP連携の説明](docs/SPEC.md#mcp連携chatgptなど)を参照してください。

### X連携

「外部連携」でXのAPIトークンを登録すると、投稿URLから本文を保存できます。Xの開発者契約・読み取り権限・利用枠が必要です。取得できない場合は、ストックの詳細画面で本文を貼り付けて補完できます。[X連携の詳細](docs/SPEC.md#x連携)を参照してください。

### YouTubeの動画を表示する

動画URLとメモを保存し、一覧のサムネイルから詳細画面を開いて再生できます。再生できない場合は「YouTubeで開く」からご覧ください。

動画内容の取得や自動要約・問いの生成は行わず、自分で書いたメモだけをメモリに反映します。サムネイルやプレーヤーの表示・再生時にはYouTubeへ通信します。[動画表示と取得範囲の詳細](docs/SPEC.md#記事取得の範囲)を参照してください。

## プロジェクトの公開

プロジェクトの「設定」→「公開設定」で公開できます。初期状態は非公開です。公開すると共有用URLが発行され、ログイン前のトップページにも掲載されます。

- プロジェクト名・公開用の紹介文、ストックのタイトル・URL・要約・要点・トピック、問い、プ譜の最新局面と振り返りが公開されます。
- メモリ・個人メモ・取得本文・内部用のプロジェクト概要は公開しません。ただし、プ譜そのものに書いた内容は公開されます。
- 公開後の追加・編集も反映されます。非公開にするとトップ掲載とURLからの参照が停止します。

公開前に内容を確認してください。[公開範囲と設定の詳細](docs/SPEC.md#プロジェクトの公開)を参照してください。
