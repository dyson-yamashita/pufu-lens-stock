# Miniflareの同期RPC修正

`miniflare@4.20260730.0.patch` は、Cloudflare公式の[修正 #15552](https://github.com/cloudflare/workers-sdk/pull/15552)を安定版Miniflare 4へ適用します。

古い実装では、前リクエストの遅延した通知で次の待機が解除されると、応答を受け取る前に `message?.id === id` の検証が失敗します。CIではD1の初期化中に発生しました。通知の値をリクエストごとの世代番号にし、対象の応答が届くまで待機する、上流と同じ修正です。

`pnpm-workspace.yaml` の `patchedDependencies` とロックファイルで登録しているため、通常の `pnpm install --frozen-lockfile` で適用されます。テストのスキップ・再試行・並列数の削減は行いません。

`tests/miniflare-sync.test.ts` は待機が早く解除される状態を再現し、実際のD1呼び出しと後続の呼び出しが成功することを確認します。パッチ適用前はCIと同じ検証エラーで失敗します。

修正を含む安定版に更新する際は、このパッチと登録を削除し、回帰テストの成功を確認してください。

# pufu-editorの公開プレビュー修正

`@goto-lab__pufu-editor@0.9.14.patch` は、`ProjectScore` のモバイル表示で8要素へ `preview` が渡されていない箇所を補います。PC表示と同じ設定を渡すことで、8要素とその振り返りも読み取り専用になり、編集用のUIを表示しません。プレビュー時の施策のドラッグ並べ替えも無効にします。

また、同じ施策文でも振り返り・進捗・色が異なる場合は個別に表示します。プレビューの共有施策判定をこれらの値を含むキーで統一し、接続線も同じ判定にします。通常の編集モードの共有判定・入力・追加・並べ替えは維持します。

公開プ譜にはライブラリのプレビューを使い、保存処理や生成処理は組み込みません。`tests/public-score-ui.test.ts` は実際のライブラリを描画し、PC・スマホとライト・ダークの全入力が読み取り専用かつドラッグが無効で、全要素・施策・個別の振り返り・進捗が表示されることを確認します。通常の編集モードの継続利用も確認します。修正前はスマホの8要素が編集可能になるため失敗します。

この修正を含む版へ更新する際は、このパッチと登録を削除し、上記テストの成功を確認してください。
