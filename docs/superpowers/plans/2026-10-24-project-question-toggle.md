# プロジェクト別の問い自動生成トグル Implementation Plan

**Goal:** プロジェクトの「詳細設定」から、ストックに由来する問いの自動生成をオン・オフできるようにする。

**Architecture:** D1のprojectsに既定値オンの設定を追加し、作成・更新・一覧APIと既存のProjectFormで共有する。問いの登録、短文メモ変更時の再生成、未開始ジョブの起動で設定を確認する。

**Tech Stack:** React、TypeScript、Hono、Cloudflare D1 / Workflows、Vitest / Miniflare。

**Spec:** ユーザーの依頼と添付画像。作成画面・設定画面の「詳細設定」で既存の「一覧に表示する」「ユーザーのメモリを更新する」を維持し、その下に「ストックから問いを自動生成する」を追加する。既存のプロジェクトはオンを維持し、生成済みの問い、手動の問い、記事の要約・メモリの更新設定は保持する。開始済みの生成は完了できる。既存の待機期限・再試行上限は維持し、過去ストックの遡及生成は追加しない。
