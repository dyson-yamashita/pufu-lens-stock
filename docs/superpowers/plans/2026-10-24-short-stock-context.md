# 短いストックとひとことメモの実装計画

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 短い投稿から推測の要点を作らず、気になった理由を問いとメモリへ反映する。

**Architecture:** 前後の空白を除いた本文が120文字未満ならAI要約を呼ばず、原文と1つの要点だけを保存する。短文の識別は要約JSONに任意の `shortSource` を保持し、既存データとの互換性を保つ。記事要約は本文だけの事実として維持し、保存先ごとの私的メモは問い・メモリの入力として区別する。

**Tech Stack:** TypeScript、React、Hono、D1、R2、Cloudflare Workflows、既存Vitest。

**Spec:** Grokストック `a218e411-0d6c-49af-a724-25f6458c6a4b`。本文120文字未満は提案中の初期値を採用。意味の薄い長文は通常のAI要約で要点の水増しを禁止する。

## Global Constraints

- main起点の独立PR。新依存とDBマイグレーションを追加しない。
- 本番の既存記事を一括再生成・変更しない。
- 原文と私的メモを混在させず、他の保存先の要約へメモを漏らさない。
- ユーザーの問い・削除済みAIの問い・プ譜を保持する。

## Review Focus

- 日本語・絵文字の119/120文字境界と空白。
- メモ更新の重複、同時更新、古い問い生成の完了。
- 利用上限時にメモを保存でき、既存の待機・再試行上限で生成を抑える。
- 同じ記事を別プロジェクトへ保存したときの独立性。
- 保存エラー時の入力保持、キーボード操作、スマホとダークモード。
