## 全体の表現

紺色を基調に、淡い青灰色のページ背景と白いカードで情報を整理しています。本文と問いを読みやすく置き、枠線・余白・文字の大きさでまとまりを示します。通常のカードは影を使わず、ダイアログだけに影と背景のぼかしを付けています。

ロゴは [pufu-lens-logo.png](../public/pufu-lens-logo.png) と「Pufu Lens」の文字を横並びにします。画像は38 × 38px、角丸11px。文字全体は同じ太さで、Lensだけを強調しません。サイドメニューには英語のタグラインや「好奇心に、置き場所を。」「あなただけのライブラリ」の補足文を表示しません。

## 文字とアイコン

- フォントは `DM Sans`、`Noto Sans JP`、`sans-serif` の順です。Google Fontsから読み込みます。
- ページ見出しは基本28px・太さ600。幅1,250px以下では25pxです。
- ストックのタイトルは16px・太さ600、要約は14px・行間1.9です。
- 問いの本文は一覧と詳細で共通の23px・太さ500・行間1.9。幅760px以下では19pxになります。
- ナビゲーションは13px、補助文はおおむね10〜13pxです。入力欄の値とプレースホルダーは別の色を使います。
- 本文の改行を保持し、長いURLや語句は必要に応じて折り返します。プロジェクト名など一部の短い欄は省略記号を使います。
- アイコンは主に `lucide-react` の線画を使います。スターの線幅は1.5で、選択時だけ塗りつぶします。プ譜内部はエディターのアイコンを使います。

文字サイズは画面幅の指定に加え、CSS末尾の共通指定でも上書きされています。変更時は最終的に適用されるルールを確認してください。

## 画面の骨格とナビゲーション

### デスクトップ

左に固定サイドメニュー、右にヘッダーと本文を置きます。サイドメニューは幅248px、幅1,250px以下では224pxです。本文領域はサイドメニューの幅だけ左側を空けます。

ヘッダーは基本高さ71pxで、日本語のパンくずリンクを表示します。本文は最大幅1,600px、中央寄せ、基本の左右余白は40pxです。ページ見出し・説明の右に操作ボタンを置き、全体一覧のプロジェクト選択はそのボタンの左側に配置します。

### サイドメニュー

表示順は次のとおりです。

1. ロゴ
2. すべての記事（遷移先の見出しは「すべてのストック」）
3. すべての問い
4. あなたのメモリ
5. プロジェクト一覧・追加
6. プロフィール、ショートカット連携、MCP連携
7. ユーザー名・メールアドレスまたはデモ表示・ログアウト

開いているときはメニュー右上の「×」で閉じます。閉じているときはヘッダーのハンバーガーから開きます。広い画面でも折りたため、閉じると本文領域が広がります。開閉状態は画面内の状態として保持し、ページ再読み込みをまたいで保存しません。

### 一覧とプロジェクトの切り替え

全体画面のプロジェクト選択は一覧の絞り込みです。選択しても画面とURLは維持し、ストック／問いのタブ間で保存先の選択を引き継ぎます。サイドメニューからプロジェクトを選ぶと専用画面へ移動します。

全体一覧のタブは「ストック」「問い」。プロジェクト専用画面は「ストック」「問い」「メモリ」「設定」の順で、選択中の文字と下線を紺色にします。専用画面ではプロジェクト選択メニューを表示しません。

主な画面は次のハッシュURLで切り替えます。ストックの詳細は独立したURLではなくダイアログです。

| URL                       | 画面                         |
| ------------------------- | ---------------------------- |
| `#`                       | すべてのストック             |
| `#questions`              | すべての問い                 |
| `#project/:id`            | プロジェクトのストック       |
| `#questions/:id`          | プロジェクトの問い           |
| `#memory` / `#memory/:id` | あなた／プロジェクトのメモリ |
| `#settings/:id`           | プロジェクト設定             |
| `#profile`                | プロフィール                 |
| `#shortcuts`              | ショートカット連携           |
| `#mcp`                    | MCP連携の設定説明・連携一覧  |
| `#question/:id`           | 問いの詳細                   |
| `#resolve/:id`            | 課題の入力                   |
| `#pufu/:id`               | プ譜の表示・編集             |

## 共通コンポーネント

### ボタンと入力欄

主ボタンは紺地に白文字、副ボタンは白地に青灰色の枠線。角丸は7px、基本の高さは44px以上です。フォームの確定操作やページ上部の追加ボタンは右寄せにします。

入力欄は白地・1pxの枠線・角丸8px、基本の高さは46px以上。ラベルを入力欄の上に置き、任意・文字数・エラーなどを近くに表示します。テキストエリアは縦方向にサイズを変更できます。プロジェクト選択の下向きアイコンは右端から16px内側に置きます。

### 検索とフィルター

検索欄は左に虫眼鏡、右にクリア用の「×」を置きます。ストック一覧・問い一覧は、虫眼鏡またはEnterで検索し、入力中には結果を変えません。「×」は入力値と適用済み検索条件を解除します。横に更新ボタンは置きません。問い追加フォーム内の紐づけ先検索は、別の簡易入力欄で入力後250msに反映します。

検索欄の下にフィルターを左寄せ、件数を右寄せで配置します。選択中は淡い青灰色の背景と紺色の文字です。

- ストック：すべて／web／ユーザー／お気に入り
- 問い：AI／ユーザー／お気に入り。選択中のものを再度押すと全件表示に戻る

### ラベルとお気に入り

「AI」は淡い青灰色、「ユーザー」は白地に枠線、「プ譜」は選択色の背景で表示します。「プ譜」は生成済みのプ譜がある問いだけに付けます。作成元のラベルと生成状態は区別し、生成中や失敗はメッセージで伝えます。

スターは未選択なら背景透過の枠線、選択すると黄色の塗りつぶしです。ストックと問いのお気に入りは別々に操作します。

### ダイアログ

追加フォームやストック詳細にはHTMLの `dialog` を使います。通常は最大510px、詳細は最大710px。角丸15px、内側余白27px、画面から上下24px以上の余裕を確保し、長い内容は内部をスクロールします。背景は半透明の紺色と3pxのぼかし。右上に閉じるボタンがあります。

## 画面ごとの構成

### ストック一覧・詳細

一覧カードは白地・細い枠線・角丸10pxです。上から次の順に並びます。

1. Webは地球儀アイコンとドメイン、テキストは本アイコンと「テキスト」、右寄せの処理状態
2. 記事タイトル
3. 要約の抜粋
4. トピックのタグ
5. 区切り線の下にプロジェクト、日付、スター、元の記事へのリンク

要約済みの状態ラベルは表示しません。処理待ち・本文取得中・要約生成中・取得失敗のラベルはカード上部の右側です。

広い画面の一覧は記事カードとメモリ欄の2領域で構成します。メモリ欄には関心・知識の要点とショートカット連携への案内を置きます。メモリ下部には生成元の記事数と更新日を表示し、詳細へ進む矢印は置きません。ショートカット案内のダウンロードアイコンは「見つけた、そのときに。」の見出しと横並びにします。

詳細ダイアログにはタイトル、元の記事を開くリンク、その行の右端に「☆ お気に入り」を置きます。テキスト保存では外部リンクは表示しません。タブは「要約」「問い」「メモ・保存先」「取得した本文」（テキストでは「入力した本文」）。削除操作は下部に置きます。

### 問い一覧・詳細

一覧と詳細は同じカード構造を使い、白地・角丸12px・内側余白28pxです。

1. 上段左にAI／ユーザーとプ譜のラベル、右にプロジェクト
2. 大きな問いの本文
3. 本のアイコン、紐づくストックのタイトル、右向き矢印
4. 区切り線の下に日付、右端にスター

一覧のカード左上には、はてなアイコンを置きません。ストック詳細の「この記事から生まれた問い」では見出し用のはてなアイコンを使っています。

問い詳細の下に作成済みプ譜の一覧と「問いの解決を考える」を置き、さらに下に「問いを削除」を右寄せします。問いの本文から詳細へ進み、紐づくストックのリンクから記事詳細を開きます。

問い追加フォームではプロジェクトを選び、ストックは任意で紐づけます。「ストックを紐づけずに保存」で独立した問いを保存でき、ストックのないカードや詳細には記事リンクを表示しません。

### 課題入力・プ譜

課題入力画面は、上に問いのカード、下に「問いを解決する課題」のフォームと「プ譜を作成」を置きます。入力した課題が獲得目標になることを補助文で示します。

プ譜画面では、上から「問い」「課題（獲得目標）」のラベルと本文、プロジェクト名を表示します。この2つのラベルはオレンジ系で、まとまりの左側に紺色の縦線を付けます。

その下に局面の切り替え、保存状態、JSONダウンロード・局面追加・保存のボタン、エディターを置きます。局面切り替えは「◀ 第n局面 ▶」で、移動先がある矢印だけを表示します。切り替え部分に背景色や枠線はありません。局面名に「（編集）」は付けません。

奇数局面は編集、偶数局面はフィードバックモードです。過去の局面も編集・保存でき、「局面を追加」は最新局面だけで表示します。未保存の変更があるときは、移動・局面切り替え・ページ離脱時に確認します。

エディターはReactコンポーネントの直接組み込みです。幅1,000pxを超える場合は白い外枠を付け、幅1,000px以下では外枠とエディター全体の枠線を消します。項目ごとの枠は残ります。縦並びでは獲得目標と勝利条件の領域を上に置きます。

エディター下部に、生成で参照したユーザー／プロジェクトメモリの時点と、エディターの著作権・ライセンスへのリンクを表示します。

### メモリ

「興味の傾向」「記事から得た知識」を整理し、根拠となる記事への導線を付けます。メモリの詳細画面では、内容があれば「未解決の論点」も表示します。再生成とテキストのダウンロードを用意し、更新待ち・空の状態も説明文で示します。ユーザー全体とプロジェクトの両方に対応します。

「記事から得た知識」の各項目は最初の3行まで表示します。実際に3行を超える項目だけ「続きを読む」を根拠記事のリンクと同じ行に置き、展開中は「閉じる」に切り替えます。画面幅が変わった場合も表示量を再判定し、短い項目には展開操作を表示しません。全文と根拠記事への導線は保持します。

「あなたのメモリ」には対象セレクターを置かず、プロジェクト別のメモリは各プロジェクトの「メモリ」タブから開きます。反映済み・未反映・要約未完了の件数は、再生成ダイアログで確認できます。

### プロフィール・プロジェクト設定

白地・枠線・角丸12px、最大幅680pxのフォームです。プロフィールには名前と自己紹介、プロジェクト設定には名前とプロジェクト概要を置きます。プロフィールの見出し下には説明文を置きません。プロジェクトの説明は「プロジェクトの設定を編集できます。」、保存ボタンは「保存」です。

自己紹介のプレースホルダー：

```text
以下について書いてみましょう。
・関心のあること、取り組みたいテーマ
・役割や経験、得意分野
・大切にしている考え方や進め方
・普段関わる人やコミュニティ
・仕事や活動の環境、使い慣れた技術や道具
```

プロジェクト概要のプレースホルダー：

```text
以下について書いてみましょう。
・実現したいこと、取り組む目的
・使える時間や予算
・利用できる技術や道具、活動環境
・競合する活動、気になる問題
```

### ログイン・ショートカット連携

ログイン画面はロゴ・紹介文・Googleログイン・機能を表すカードのイラストで構成します。ローカルデモが有効な場合だけデモ開始ボタンを表示します。

ショートカット連携画面は設定手順とAPIの例、トークン一覧、発行フォームで構成します。発行結果はコピーできる入力欄に表示し、保存先制限と有効期限（無期限を含む）を選べます。秘密のトークン全体は発行時だけ表示します。

### MCP連携

設定説明画面にはMCPサーバーURLとコピーボタン、会話からの利用例、接続中のサービス一覧と連携解除を置きます。認可画面では接続元と送信先を表示し、許可する操作と対象プロジェクトを選びます。[設定説明](screenshots/mcp-settings.jpg)と[認可画面](screenshots/mcp-authorization.jpg)のキャプチャはローカルデモで撮影しています。

URLは接続一覧の読み込み中や取得失敗時にも表示します。本番の接続設定が未完了の場合は、その状態と設定完了後に連携できることを案内します。接続一覧を取得できない状態は「連携なし」と区別します。

## レスポンシブ表示

画面全体とプ譜エディターで異なる境界を使います。数値はCSSピクセルで、以下は主な切り替えです。

| 画面幅      | 主な表示                                                                    |
| ----------- | --------------------------------------------------------------------------- |
| 1,600px以上 | 本文上余白45px、ストックカード内余白23px                                    |
| 1,250px以下 | サイドメニュー224px、本文左右余白28px、記事カード1列                        |
| 1,000px以下 | プ譜は縦並び・全体の枠線なし                                                |
| 960px以下   | 一覧とメモリの主領域を1列にし、記事カードは2列、メモリ欄内は2列             |
| 760px以下   | サイドメニューを幅250pxのオーバーレイに変更、ヘッダー62px、操作欄は次の行へ |
| 600px以下   | 本文左右余白17px、記事カードとメモリ欄を各1列、プロジェクトのタブを均等配置 |

760px以下のサイドメニューは「×」・背景タップ・Escapeで閉じます。表示中は本文を操作対象外にし、開閉に合わせてフォーカスを移します。広い画面の折りたたみ状態とモバイルの開閉状態は別に管理します。

問い一覧は固定の列数ではなく、最小幅420pxを基準とした可変グリッドです。問い詳細は最大900px、問い一覧は最大1,100pxです。

## 状態と操作の伝え方

- 読み込み中・保存中にはスピナーとテキストを表示し、連打を避けるため対象の操作を無効にします。
- 結果がない場合は、未登録と検索結果0件で説明を変えます。
- エラーは対象フォームの近く、またはページ上部に表示します。利用制限の場合は理由と再試行目安を伝えます。
- 成功通知や保存状態には `role="status"`、エラーには `role="alert"` を使います。
- アイコンだけのボタンにも `aria-label` を付け、お気に入りやフィルターは `aria-pressed` で状態を示します。
- キーボードフォーカスは基本3px、エディター内は2pxの青いアウトラインで示します。
- 削除や未保存のままの移動にはブラウザの確認ダイアログを使います。
- `prefers-reduced-motion: reduce` の場合はアニメーションとトランジションを無効にします。
- ローカルデモではヘッダー下のバナーで、AI未接続の本文抜粋か、Workers AI利用中かを示します。本番ではデモ用バナーを表示しません。
