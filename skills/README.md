# Pufu Lensのスキル

利用者のCodex・Claude Codeなどで実行するAgent Skillsです。推論は利用者のAIの利用枠を使い、Pufu Lensへのデータ取得・保存には既存のMCP接続を使います。スキルの導入だけではMCP接続や認可は完了しません。

| スキル                                        | 用途                                                                                               |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| [deepen-questions](deepen-questions/SKILL.md) | 複数ストック・既存の問い・本人の意見から仮説を立て、それを確かめる問いと判断条件・確かめ方を考える |
| [compose-pufu](compose-pufu/SKILL.md)         | 複数の問い・ストック・本人の意見を参照し、根拠と提案を分けてプ譜を組み立て、依頼に応じて保存する   |

`deepen-questions` と `compose-pufu` の資料探索は、通常1回の検討で最大3回までハイブリッド検索を使い、Pufu Lensの検索用AIの利用枠を消費します。単語検索のみの指定も可能です。仮説・問い・プ譜を考える推論は利用者側のAIで行います。

`compose-pufu` は既存のMCPで複数の材料を読み、利用者側のAIでプ譜を構成します。MCPからの登録では、採用した同じプロジェクトの問い・ストックをそれぞれ100件まで関連付けできます。画面でAI自動生成する際の各1件制限とは別です。Pufu Lens側のプ譜のAI生成は呼びません。

インストール方法・利用条件・使い方は、Pufu Lensのユーザーマニュアルの「スキルで問いを深め、プ譜を作る」を参照してください。外部連携ページからも開けます。配布には[skills CLI](https://github.com/vercel-labs/skills)を使い、取得先をこのディレクトリに限定します。リポジトリルートを指定すると、開発用 `.agents/skills/` も探索対象になるため、マニュアルのURLを使ってください。

## スキルを追加・更新する開発者向け

- 新しいスキルは `skills/<skill-name>/SKILL.md` に置き、frontmatterにディレクトリと一致する `name` と、使う場面を記した `description` を設定します。
- 一つのスキルは一つの利用目的に絞ります。参照資料や評価ケースはスキル自身のディレクトリ内に置き、単独インストールでも動くようにします。
- 利用者の入力・設定を優先します。秘密情報、APIキー、個人データ、固定の個人用IDを同梱しません。MCP接続先は利用者の外部連携ページで確認し、認可はクライアントに任せます。
- `metadata.version` を更新し、この一覧とマニュアルを必要に応じて更新します。配布するスキルと開発用 `.agents/skills/` は独立して管理します。
- `evals/` の架空データで、スキルを読み込まない場合と読み込んだ場合を比較します。実データを保存せず、候補の質・取得範囲・登録判断・機密性を確認します。
- 公開前にskills CLIで限定パスの一覧・隔離した導入先を確認します。更新・追加は利用者のCLIから取得し、既存インストールの自動更新を前提にしません。
