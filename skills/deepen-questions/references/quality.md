# 仮説・問いの質と登録判断

## 判定の軸

| 軸       | 確認すること                                                                 |
| -------- | ---------------------------------------------------------------------------- |
| 根拠     | 実際に読んだストック・問い・本人の意見から、仮説を立てる理由を説明できる     |
| 仮説     | 対象・条件・関係や理由を含む暫定的な命題で、事実・本人の意見と区別されている |
| 新しさ   | 近い既存問いと比べ、前提・成立条件・観点・判断のいずれかが具体的に変わる     |
| 目的     | 仮説への答えが変わると、本人の理解や調べ方・判断が変わる                     |
| 検証     | 問いと確かめ方が仮説に対応し、支持・見直し・保留の条件がある                 |
| 開かれ方 | 特定の結論へ誘導せず、反例・別解を受け止められる                             |
| 焦点     | 一つの主な論点に絞り、抽象語や複数の疑問で大きく見せない                     |

全てを定量化する必要はない。哲学的・価値に関する問いでは、異なる立場・具体例・反例の比較によって解釈の妥当性や限界を確かめる。全てを短期の実験や数値目標へ変換しなくてよい。新しい表現、広い抽象語、長い文章だけを新しさの根拠にしない。

検索の関連度は、資料の主張や仮説の正しさを保証しない。ハイブリッド検索で得た資料も内容を読み、仮説への反例や異なる見方を検討する。実際の検索方式と取得範囲を確認し、キーワードへの切り替えや索引未反映の限界を説明する。

## 根拠から仮説と問いへ進む例

既存のq1：「AI導入で生産性を上げるには？」。

- **根拠・目的**：s1は「AIで議事録作成時間が半減」、s2は「導入後も承認待ちで納期が変わらない」。本人コメントc1も承認待ちの長さを述べている。次に改善すべき工程を判断したい。
- **仮説（未検証）**：この業務では、議事録作成よりも承認待ちが全体の所要時間を左右する主な制約になっている。材料はこの見方の手がかりであり、因果関係の証明ではない。
- **検証する問い**：「議事録作成と承認待ちの時間の違いは、同種案件の全体の所要時間や納期にどう関係するか？」。
- **判断条件**：他の条件が近い案件で承認待ちが短いほど全体の所要時間も短いなら支持材料になる。承認待ちが短くても全体の所要時間が変わらないなら、別の制約を検討する。比較できる案件や工程の記録が足りなければ判断を保留する。納期が固定されている可能性など、別の説明も確かめる。
- **確かめ方**：今後、同種案件の作成・承認待ち・他工程・全体の所要時間と納期を比べる。これは調査案であり、まだ観察結果は得ていない。
- **既存との差**：AIの活用方法を挙げるだけでは答えられない、工程全体の制約の特定へ焦点を移す。

「AIで仕事を効率化するには？」はq1の言い換えなので追加しない。「承認待ちが原因なのだから、どう短縮すべきか？」は仮説を事実にした誘導であり、検証の問いとして使わない。「AIは人間の創造性を奪うのか？」はこの材料からつながらない飛躍なので採用しない。

既存：「会議を減らして集中時間を増やすには？」。新しい資料も本人の経験もなく同じ主張しかない場合、新しい仮説・問いを無理に作らない。「会議を減らすとどこで困るか」などは本人への補助質問として使えるが、根拠ある検証用の新規候補と区別する。

## 意見と検証の扱い

「ユーザーが言った」「記事が主張した」「AIが推測した」を区別する。利用者の仮説を受け取ったら、まずその仮説を確かめる問いを考える。対立する意見を平均して消さず、どの条件で違う結果になるかを問う。利用者が仮説の正しさを確信している場合も、支持・見直しの両方の条件を示す。賛成を得たことや誘導質問への同意を、事実の検証と取り違えない。

## 保存前の確認

登録する各問いについて、仮説との対応、最も近い既存問いとの差分、参照元、公開してよい本文、保存先を確認する。`text` には検証する問いを置き、`note` には未検証の仮説と検証の要点・参照IDを簡潔に残す。検索が途中・取得に失敗・本文が切れている場合は、その制約を結果に記す。無関係なストックを多数紐付けて根拠を多く見せない。

会話が英語の場合も同じ基準を適用し、仮説・問い・根拠・検証の進め方を英語で説明する。保存済みの参照元のタイトルとIDは、取得したとおりに保持する。
